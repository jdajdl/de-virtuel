# Dé virtuel

Dé virtuel (1 à 3 dés) : toucher ou secouer le téléphone pour lancer.

- **PWA** (racine) : `index.html`, installable et utilisable hors ligne. Publiée via GitHub Pages.
- **Android** (`android/`) : projet Android Studio en Kotlin.

Si vous modifiez les fichiers de la PWA, changez `VERSION` dans `sw.js` pour forcer la mise à jour du cache.
